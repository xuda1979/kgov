三、软件主要功能与技术特点
════════════════════════════════════════════════════════════════════

软件首页：
    本软件是一款面向中小企业信息团队的 Kafka 主题治理助手，自托管、
可离线运行，涵盖“模式演进治理—数据质量治理—治理报告”全流程，为
Kafka + Schema Registry 环境提供轻量、可 CI 集成的治理能力。

主要功能：
    1、Schema 演进兼容性检测（schema-diff）
       对两个 Avro / JSON Schema 进行逐字段、逐类型对比，自动判定
       Breaking（破坏性）、Non-Breaking（非破坏性）、Additive（新增
       兼容）三种兼容级别，输出 Markdown 升级指引或 JSON 兼容性矩阵；
       Baz 从本地文件或在线 Schema Registry 读取模式，支持
       “registry 地址/主题/版本号”的简写引用。
    2、脏数据规则扫描（check）
       提供类 JSON / YAML 的规则 DSL，可对消息字段进行类型、必填、
       枚举、正则、数值范围、非空等约束校验；对已入队消息逐条执行
       规则，输出违规样本（主题 / 分区 / 偏移量 / 键 / 字段 / 失败项），
       并以退出码作为 CI 门禁，未指定数据源时拒绝扫描以避免空扫描
       静默通过。
    3、治理报告生成（report）
       汇总主题清单，标注负责人（owner）、主题标签、Schema 注册状态、
       陈旧度（按消费组最近消费时间或最近消息时间计算，阈值可配置）、
       违规计数，支持 CSV / JSON 导出，适合定时任务（cron）巡检。
    4、Schema Registry 客户端（registry）
       遵循 Confluent Wire 协议直接访问在线注册表，拉取主题 / 模式 /
       兼容级别；内置本地 MockRegistry（只读 HTTP 服务），无注册表时
       可离线提供真实 HTTP 往返。
    5、真实 Broker 对接（可选，broker 扩展）
       通过 confluent-kafka 拉取主题元数据、消费组状态并读取线上消息；
       消息值优先按 JSON 解析，无法解析且带注册表时按 Confluent Wire
       格式（0x00 魔数 + 4 字节大端 Schema ID + Avro 二进制负载）解码，
       解码失败回退为文本 / 十六进制，扫描不中断。

技术特点与创新点：
    1、自托管 / 离线优先：全部核心功能基于 JSON / YAML 数据包离线运
       行，不依赖任何云服务，适合内网与保密环境。
    2、双引擎模式对比：同一兼容性分类框架同时支撑 Avro 与 JSON Schema
       两种模式体系，判定规则统一、输出格式一致。
    3、规则即代码：用声明式 DSL 表达数据质量约束，校验逻辑与业务字段
       解耦，可随消息字段动态扩展。
    4、社区级“门禁式”退出码约定：0/1/2/3 四级退出码让治理工具可直接
       接入 CI 流水线作为非强制检查卡点。
    5、渐进式解码链路：JSON→Confluent Wire Avro→文本/十六进制 的自适
       应解码，保证扫描任何载荷都不会中断。
    6、面向中小团队的全流程闭环：diff（演进）→ check（质量）→ report
       （治理）三位一体，一次安装即可完成主题治理闭环。
